# Oğuz Mert Coşkun — Engineering Portfolio

Static HTML/CSS site for GitHub Pages. Upload **the contents of this directory** to the root of your `Omert2004.github.io` repository and enable Pages from `main` / `/ (root)`.

## Content and approach

Project writing follows the technical case-study pattern: **objective → contribution/implementation → verification or limitations**. It is based on the engineering portfolio PPTX, Trento project-closure PPTX, and TEI / SAVRONIK internship reports. School emblems are linked externally; company/team marks come from the portfolio presentation.

Report figure extracts: `tei-event-timeline.webp` (TEI report p. 6); `tei-hardware.webp` (p. 8); `tei-flash-records.webp` (p. 17); `sav-architecture.webp` (SAVRONIK report p. 9); `sav-kl25z.webp` (p. 8); `sav-monitor-test.webp` (p. 15). Other figures are adapted from the uploaded presentations.

Review third-party logo / internship image permissions before publishing. No source internship PDFs, supervisor contact details or restricted documents are bundled with this site.

## Editing

Edit `index.html` to update project text and links, `styles.css` for the layout. All local pictures reside in `assets/`. No build tools are required.

BAYKON report additions: `baykon-indicator.webp`, `baykon-serial-new.webp` (p. 17), and `baykon-test-bench.webp` (p. 18). SAVRONIK architecture, board, C# monitor and Hercules test are separate figure crops from pp. 8, 9 and 15.
