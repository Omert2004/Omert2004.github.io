# Oğuz Mert Coşkun — Engineering Portfolio

Static, responsive engineering portfolio for GitHub Pages, based on the two provided presentation decks.

## Publish at `Omert2004.github.io`

1. Sign in to GitHub as **Omert2004**.
2. Create a **public** repository named `Omert2004.github.io` (if you already have it, use that repository).
3. Upload **all contents of this folder** to the repository root (`index.html`, `styles.css`, `script.js`, `assets/`, and optional `README.md`). Do not upload only the ZIP.
4. Go to **Settings → Pages → Build and deployment**. Select **Deploy from a branch**, branch `main`, and folder `/ (root)`, then save.
5. Once Pages finishes deploying, visit **https://omert2004.github.io/**.

Alternatively, publish in any repository: visit Settings → Pages and deploy from `main` / `(root)`; its URL will typically be `https://omert2004.github.io/REPO/`.

## Local preview

Open `index.html` in a web browser. The website does not require a build system or backend. Fonts load from Google Fonts when internet is available; local fallback fonts are provided.

## Editing

- `index.html`: page structure, project summaries, links, and personal information.
- `styles.css`: colors, layout, and responsive styles.
- `script.js`: technical project case studies, modal behavior, and mobile navigation.
- `assets/`: selected visuals derived from the presentations.
